Hold any key and a menu rises out of it, like holding an app icon on the Home Screen. The top card is always the value, shown in full; tap it to insert. Below it come only the options that make sense for that field. 2 · Menu and settings in the app's palette

The 13c mock used a black selected segment, a solid blue menu circle and grey monospace chips. None of those exist in the app. The app's chip rule is: selected = white fill with a hairline border, ink text; unselected = text only in grey (Library filter chips, design-system.md). The keyboard now uses exactly that. The active menu circle and the active scan circle use the same accent-filled circle as the app's Scan button. Done and Back stay accent, as today.
