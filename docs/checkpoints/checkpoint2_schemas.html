Checkpoint 2 — Extraction schemas

Five document types. For each: raw OCR text as Apple Vision would return it → fields the model must fill → the check that proves the field is right. The checkers below are live; the same code goes into the app.

OCR lines→type classifier→rule layer (regex, MRZ, Luhn, NRIC, 身份证)→on-device model fills the rest→review screen

Rule: anything a checksum can verify is done in code, not by the model. The model only handles layout and language.

Language rule: ≥60% CJK characters → 中文 summary. Otherwise English. Mixed documents → ask once.

7 · Questions for you

Q1 · Race / ethnicity / blood group appear on NRIC and 身份证. Store them, or drop them at capture? I propose drop by default, toggle per document.
Q2 · CVV: store encrypted like the PAN, or never store (you type it at checkout)? I propose store, hold-to-reveal, since the point is fast checkout.
Q3 · Pinyin for Chinese names on forms: Hanyu Pinyin upper-case, surname first ("WANG WEI")? Or ask per person?
Q4 · Anything missing from the five types for milestone 1? Candidates: driving licence, bank statement, visa page, 营业执照.
