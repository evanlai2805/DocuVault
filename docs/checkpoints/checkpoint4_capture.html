C · OCR settings I plan to use

SettingValueWhy
Recognition levelaccurateSpeed is fine on A19 Pro; accuracy matters for IDs
Languageszh-Hans, en-US (both always on)Mixed documents are common; Vision handles both in one pass
Language correctionoff for IDs and cards, on for proseCorrection "fixes" passport numbers and MRZ into words. Decided after a quick first pass detects an MRZ or card-like line
Minimum text height1% of imageCatches small print on receipts and the MRZ
Custom wordsSGD, GST, NRIC, UEN, 增值税, 发票, 统一社会信用代码Vision lets us bias toward domain terms
Output kepttext · bounding box · confidence per lineBoxes let Phase 3 read fields by position (label left, value right)
Image storedJPEG q0.85, long edge ≤ 3000 pxEnough for re-OCR; ~1 MB per page

D · Questions

Q1 · Traditional Chinese (zh-Hant) too? Costs nothing extra. Useful for HK/Taiwan documents. Default I propose: on.
Q2 · Handwriting: Vision reads it, but accuracy on Chinese handwriting is poor. Include and mark amber, or skip handwriting for now?
Q3 · PDF import of text PDFs (not scans): use the PDF's own text and skip OCR? Faster and exact. Default: yes.
Q4 · Where does the Library live before the Vault exists (Phase 4)? Proposal: Library saves plain documents now; vault types just get a "Vault — coming" badge until Phase 4.
