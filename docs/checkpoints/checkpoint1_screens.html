C · On-device vs cloud

OCRApple Vision · EN + zh-Hans · always on-device
Classify + extractApple on-device model, structured output · MRZ + Luhn checks in code
Summary / chatQwen3-4B via MLX for 中文-heavy docs · Apple model for short EN tasks
StorageSQLite, AES-GCM per record · key in Secure Enclave · Face ID
Keyboard fillKeyboard extension · reads vault through app group · Face ID gate
Cloud (opt-in per send)Claude API · never for vault docs · redaction preview first

D · Open questions

Q1 · Keyboard extension for filling, or copy-chips only? Keyboard needs you to enable it in iOS Settings once.
Q2 · Exported .md to a folder: plain text, or encrypted file that only the app can open? Default I propose: plain text with a warning.
Q3 · Client documents: do you want a "client" group that auto-expires (delete after N days)? PDPA argues yes.
Q4 · Cloud provider for summaries: Claude only, or let the user add OpenAI/Gemini keys?
Q5 · Receipt expenses: write to a CSV in Files, or keep inside the app with export?
