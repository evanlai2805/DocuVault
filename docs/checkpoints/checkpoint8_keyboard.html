Settings · one-time setup

  1. Settings → General → Keyboard → Keyboards
  2. Add New Keyboard → DocuVault
  3. Tap DocuVault → Allow Full Access → Allow
  4. In any text field: hold 🌐 → DocuVault

Apple shows a warning for Full Access. It is needed so the keyboard can read the vault on this phone. The keyboard has no network code; you can read it in the repo.

Rules

RuleDetail
Values never on keysKeys show the field name and a hint (last 4, format). The value goes straight into the text field.
Face ID per sessionKeyboard unlocks via the same Keychain key as the app. Locks 60 s after the keyboard closes.
Number formattingCard number typed without spaces (most forms reject spaces). Hold the key for the spaced version.
DatesHold a date key for 6 formats. The last format used becomes the tap default.
CVVHold, not tap. Prevents accidental insertion.
SharedPer person: full name, address, postcode (parsed from address), phone, email.
Secure fieldsSome password fields block custom keyboards. iOS does this, not us; the system keyboard appears instead.
OrderingPerson "Me" first. Documents: cards, then passport, NRIC, ID, then Shared.
