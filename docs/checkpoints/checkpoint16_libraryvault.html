Checkpoint 16 · Library and vault

You asked for the Library to work like the Files app and the Vault like 1Password. I read it that way: the Library becomes a file browser (recents, folders, grid, long-press menu, select mode); the Vault becomes a password manager for documents (categories, favourites, an attention card, tap to copy, large type). Nothing here changes how documents are read, checked or sealed. All frames use today’s floating tab bar, colours and fonts.

Library · Recents→Browse · folders by type and person→Grid or list · sort · select|Vault · attention, favourites, categories, people→Item · tap copies · hold for more

Large type, 1Password’s feature for reading a number aloud over the phone or typing it into another device. Each character in its own box with its position, so “K, seven, six…” is easy to follow. Letters and digits are coloured apart so O and 0 never get confused.

Unchanged: the lock screen, the Face ID flow, the person page, the review screen and the keyboard. Library documents can still be owned by a person; the Vault still never appears in Library search. Search keeps its place in the right-hand pill.

Questions

Q1 · Library opens on Recents, Browse one tap away (frames 1 and 2). Recommended: yes. The filter chips go, because the folders do the same job.
Q2 · The navy “All-time DocuVault” stat card moves from the top of the Library to the top of Browse. Recommended: Browse only, so Recents starts with documents.
Q3 · Folders are automatic, by type. Do you also want folders you create yourself, such as one per deal? Recommended: automatic only for now; People already groups a client’s documents.
Q4 · Deleting a library document sends it to Recently deleted for 30 days. Recommended: yes. Client retention still deletes outright, as promised.
Q5 · When does a document join the red attention card? Recommended: passport within 6 months of expiry (the common entry rule abroad), NRIC, China ID and bank cards within 1 month.
Q6 · Should the bank card number be hidden (•••• 4821) until you tap Reveal, like a 1Password password? Recommended: yes for the card number only; every other field shows once the vault is open.
Q7 · Tapping a field today opens the edit sheet. In this design a tap copies, and Edit moves to the toolbar and the hold menu. Recommended: tap copies. It is what you will do most often.
Q8 · Favourites also go to the top of the keyboard’s start page. Recommended: yes, so My passport is always one tap away.
