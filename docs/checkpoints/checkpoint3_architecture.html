B · Security layers (tap)

Layer 1 · iOS Data Protection (free)Database and page images get completeFileProtection. iOS encrypts them with the device key. Unreadable while the phone is locked. Zero prompts.
stops forensic read of a locked phone.
Layer 2 · App lockFace ID on app open and after 60 s in background. Vault tab always re-prompts. Library does not.
stops someone holding your unlocked phone.
Layer 3 · Vault key (the "locked notes" layer)One AES-256 key in the Keychain, flagged this device only + biometry required. Vault field values and card images are sealed with it. The key never enters a backup.
stops iCloud/iTunes backup extraction and sync leaks. cost one Face ID prompt per vault session, ~50 lines of code.
Layer 4 · HygieneClipboard clears 60 s after a vault copy. Vault screens blur in the app switcher. Screenshot taken → warning toast (iOS cannot block it). Client documents auto-delete after N days (default 30). Cloud log keeps every send.

C · Keyboard extension — one honest cost

To read the vault, a custom keyboard must have "Allow Full Access" switched on in iOS Settings. Apple shows a scary warning. The keyboard target contains no network code, and you can check that. Setup: Settings → General → Keyboard → Keyboards → Add DocVault → Allow Full Access. Once.

Flow at checkout: tap field → globe key → DocVault keyboard → Face ID → pick person/doc → tap chip "Number" → it types. Values never appear on the keys.
