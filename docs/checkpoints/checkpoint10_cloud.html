Rules that are code, not prompt

RuleHow
Vault / sensitive docs never goCloudGate.allows(doc) is false for sensitive, for receipt / card / passport / NRIC / 身份证 / business card, and for any document with sealed pages. The UI builds no entry point; the client refuses the call too.
Always-on redactionNRIC/FIN, PRC 身份证 (18 digits, checksum), passport numbers near MRZ or "Passport No", card numbers (Luhn), phones, emails. Cannot be toggled off.
NamesEnglish: salutation + capitalised words (Mr/Ms/Dr/Mdm), "Name:" labels, two-to-three capitalised tokens before Ltd/Pte/LLP/Co. Chinese: 甲方/乙方/先生/女士/签字/姓名 followed by 2–4 han. Plus every extracted name field. Same name → same placeholder.
AmountsTextRules.findMoney spans. Placeholder keeps the currency: [AMOUNT 1 SGD] so the model can still reason about which fee is which.
RestoreReply placeholders are swapped back by exact token. Unknown placeholders stay as-is and the card shows "1 unresolved".
Per-send approvalThe sheet is the only path to ClaudeClient.send. The approval token lives for one request. No preference key exists for "always".
LogStoredCloudSend: time, doc, purpose, chars, redaction counts, model, tokens in/out, cost estimate, status (ok/failed/cancelled), and the redacted text if you keep that on.
KeyKeychain, this device only, no biometry (you paste it once). Shown masked. Deleting it disables every entry point.

Questions for you

Q1 Redaction defaults. IDs/contacts always on and locked. Names and amounts on by default, toggle per send. Dates off by default. Placeholders restored on reply. OK, or do you want amounts off by default because a contract summary reads better with figures in context?
Q2 Entry points. Only (a) the menu item "Summarise with Claude…", (b) "Use Claude instead" on a failed/unavailable card, and (c) "Ask Claude about this…" for one free-text question. Never auto, never on save. Agree? Is (c) wanted now or later?
Q3 Model and cost. Default claude-sonnet-5-5, with claude-haiku-5-5 as the cheap option in Settings. Cost on the sheet is an estimate from character count. OK?
Q4 API key. Paste into Settings, stored in Keychain (no Face ID), shown masked. Or gate "reveal / change key" behind Face ID?
Q5 Send log. Keep the redacted text that was sent (so you can audit exactly what left), 90-day retention, both adjustable. Or metadata only?
Q6 Chinese documents. Claude handles 中文 well, so the menu offers it for Chinese docs too, with the same redaction (中文 names via the 甲方/先生 rules). Fine?
